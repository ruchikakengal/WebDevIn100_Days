# 🎨 Color Flipper

A tiny app that generates a random HEX color and applies it to the page background. The current color code is displayed and can be copied with one click.

## 🧪 Features
- Random HEX color generation
- One-click copy to clipboard
- Fully responsive UI
- No libraries required

## 🚀 How to Run
Open `index.html` in your browser.

## 📁 Repo Placement
Place this folder at:
```
public/Day-101-Color-Flipper/
```
