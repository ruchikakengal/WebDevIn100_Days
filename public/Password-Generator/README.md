# 🔐 Password Generator

Generate secure passwords with adjustable length and character set toggles.

## ✨ Features
- Length control (6–32)
- Toggle lowercase, uppercase, numbers, symbols
- Copy to clipboard
- Strength indicator

## ▶️ Run
Open `index.html` in your browser.

## 📁 Repo Placement
